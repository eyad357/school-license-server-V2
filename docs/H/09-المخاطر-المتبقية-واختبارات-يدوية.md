# المخاطر المتبقية + اختبارات يدوية لما لم أستطع تنفيذه

## مخاطر متبقية
| الخطر | الأثر | التخفيف |
|---|---|---|
| لا اختبار على Windows حقيقي | احتمال خلل في الترقية/الإزالة لم يُكشف | اختبار يدوي أدناه قبل التوزيع |
| `.env` و`.sql` مكشوفان | اختراق الإدارة/القاعدة | تدوير الأسرار فورًا |
| حذف ترخيص فعلي `DELETE /licenses/:id` | فقد سجل عميل | نسخ احتياطي دوري؛ مُدقَّق؛ يمكن لاحقًا تحويله لأرشفة بقرارك |
| ضياع `device-id.json` | جهاز جديد ← يستهلك خانة | «إعادة ضبط الجهاز» من الإدارة |
| مدارس خلف NAT واحد | 429 مؤقت | رفع `API_RATE_LIMIT_MAX`؛ العميل يعيد المحاولة ولا يُبطل |
| الإبطال عبر البث غير مضمون | تأخير حتى 24 ساعة | سلوك مقصود؛ لا وعد 30 ث |
| حالة `EXPIRED` + بلا تاريخ تُعامل نشطة | (موروث) | تعديل بقرارك لاحقًا |
| طلبات webhook الدفع المتزامنة ≥ حجم pool | كان تعلّقًا؛ الآن خطأ بعد 10 ث | pool=20؛ استقبال مكرر آمن (idempotent) |
| لا حدود أمان على حجم السجل `license_events` | نمو | احتفاظ 30 يومًا؛ نظّف دوريًا (`DELETE` من الإدارة بقرارك) |
| التوقيع غير مفعّل | استعادة الدائم بعد فقد البيانات تتطلب إعادة تفعيل | فعّله بعد استقرار الإنتاج |

## اختبارات يدوية (Windows حقيقي، جهاز نظيف + جهاز عليه إصدار قديم)
1. ثبّت الإصدار القديم، فعّل بمفتاح، أغلق. شغّل مثبّت v4 فوقه. **المتوقع:** يفتح دون طلب مفتاح، نفس معرّف الجهاز (قارن `device-id.json` قبل/بعد)، بيانات المدرسة والشواهد كما هي.
2. افتح مجلد `…\Roaming\نظام التقويم والاعتماد المدرسي-license`: يجب ألا يوجد `migration-conflict.json` في الحالة العادية، وأن توجد `migration-done.json` بعد أول تشغيل.
3. أزل البرنامج من «التطبيقات». **المتوقع:** تبقى مجلدات البيانات والترخيص والشواهد. أعد التثبيت ← يفتح مفعّلًا.
4. افصل الإنترنت وأعد تشغيل الجهاز: الترخيص الدائم يعمل. اضبط تاريخ الجهاز 5 سنوات للأمام: يبقى الدائم.
5. (إن فعّلت التوقيع) احذف `state.dat` و`state.dat.bak` فقط وأعد التشغيل دون إنترنت: يُستعاد الترخيص.
6. أبطل الترخيص من اللوحة والجهاز متصل: سجّل المدة حتى يظهر الإبطال (متوقع ثوانٍ؛ والحد الأقصى 24 ساعة).
7. على Staging في Railway: شغّل `scripts/load-sse.js` مقابل قاعدة اختبار محلية لا الإنتاج، وكرّر قياس البث عبر الإنترنت الحقيقي من 3 شبكات مختلفة.
